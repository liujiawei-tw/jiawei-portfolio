Office Service Desk RAG

企業 IT 自助排查與報修

前往操作 Demo

把知識檢索、故障排查與報修流程整合在同一個入口。

Spring AI 搭配 Gemini 與 ONNX 向量嵌入檢索知識文件，並在回答旁呈現來源。獨立 Spring Boot 工單服務透過 REST 與 MCP 提供工單操作，使用 MySQL 儲存資料，並以 Flyway 管理資料庫遷移。

知識檢索與回答依據

以 VPN、辦公設備等常見問題引導員工自助排查。回應記錄檢索片段、相似度與工具呼叫，方便核對回答依據。

報修單建立與追蹤

排查後可帶入問題描述建立報修單。透過對話建單時，系統先確認必要欄位，並在工具回報成功後提供工單編號。

Taiwan Parking Forecast

找車位 — 停車位查詢與抵達預測

前往找車位 Demo

目前以新莊區作為試點，以政府停車資料為基礎，規劃停車位查詢、地點與地圖互動、資料新鮮度，以及資料不足時不輸出不可靠預測的產品規則。

資料可信度

診斷官方資料、目錄與來源對應問題，要求核對資料缺漏，並清楚區分官方即時觀測與模型估計。

產品規則

呈現資料新鮮度；來源或觀測不足時，不以推估數字假裝即時空位，也不輸出沒有足夠依據的預測。

離線模型實驗：以 31 天資料進行時間序列切分，比較 Logistic Regression 與基準模型；模型仍在實驗階段，未提供或宣稱預測成效。
